# OUTCOME

## Outcome state

### Behavior

- 利用者は、合意した Issue を渡すだけで、要求を満たし検証済みの draft PR を受け取り、承認とマージの判断だけを行っている。
- 実装・修正・テストを担当する AI は、開発中に自分の変更が持ち込んだ機能の不具合を検出し、直してから引き渡している。
- 停止した run について、利用者は停止の理由と次の対応を、証拠とともに読み取れている。

## Non-goals

- 人による承認・マージの代行
- 要求の合意がないままの実装
- GitHub Enterprise など github.com 以外のホスティングと、macOS 以外のホスト
- 対象 repo のプロダクト知識の保管

## Constraints

- Bun 1.4.4 と固定した依存で動かす。
- 対応環境は macOS のホストと github.com に限る。
- 要求と許可の正本は合意済みの Issue とする。
- main は保護され、変更は PR と人のマージだけで入る。
