# 出典確認

フレームワークやライブラリの公開 API に依存し、シグネチャ、オプション、既定値、ライフサイクル、廃止予定がバージョンで変わり得る実装では、このリファレンスを読む。

## 出典

- リポジトリのマニフェストまたはロックファイルから、導入済みバージョンを確認する。
- 該当バージョンの公式資料または原仕様を根拠にする。
- 記憶と公式資料が異なる場合は、公式資料のシグネチャを採用する。
- 判断に影響する自明でない API だけ、該当箇所へのリンクを示す。安定した標準ライブラリやプロジェクト内部のコードには付けない。

## 公式資料を確認できない場合

API について未確認であることと、不足している出典を報告する。記憶に基づく挙動を確認済みの事実として扱わない。
