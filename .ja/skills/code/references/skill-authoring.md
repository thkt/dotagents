# Skill作成

このパッケージの`skills/**`または`.ja/skills/**`を変更する依頼では、このリファレンスを読む。最初に、導入済みの Skill Creator の指示を適用する。

## パッケージの契約

- 1 つの Skill は 1 つの利用者の完了状態を扱い、操作に基づいて命名する。
- `SKILL.md`には目的、判断、権限境界、報告内容、条件付きリファレンスだけを書く。
- 決定的な検証と状態遷移は TypeScript に置く。同じ内容を文章で説明し直さない。
- `SKILL.md`に読む条件を書ける場合だけ、リファレンスを追加する。
- 依頼で変更しない限り、`agents/openai.yaml`の呼び出し方針を維持する。

## 英語版と日本語版

`.ja/`を文言の基準にし、同じ変更で英語版を更新する。

- 見出し、リンク、識別子、JSON キー、コマンド、停止状態を一致させる。
- 文章はコピーせず翻訳する。
- 英単語では操作や結果が伝わりにくい場合、日本語では具体的な語に置き換える。

## 検証

Skill 検証、文書テスト、日本語 textlint を実行する。任意の文言ではなく、動作または実際の不変条件をテストする。
