# Ship の判断

`Ship`は次の条件をすべて満たす場合だけ実行する。

- ユーザーが push と下書き PR の作成を許可している。
- 制御器が許可済みの`Ship`指示を返している。

## PR 本文の入力

`codex-build-pr-body describe`を実行する。その`input_template`を一時 JSON ファイルへ複製する。機械的に確定できる項目は、制御器とコマンドの結果だけから埋める。

人が記入する`manual_checks`と`advisories`には、確認した条件と出所を書く。`actor`が返した真偽値だけで確認済みとしない。本文生成に失敗した場合は、もっともらしい代替本文を作らない。

## 終了時の報告

`Ship`の検証が成功した後だけ PR URL を返す。それ以外では、終了指示とそれ以前のゲート分類を変更せず保持する。後片付け用に保持した`stash`は報告する。追加 Issue の候補は作成しない。
