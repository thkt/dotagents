この図の読み方

最初は工程を選んで読む表示です。各操作の進み先と、展開できる停止条件を確認できます。六つの問い・四つの評価観点は、まとめて開けます。「接続図を見る」で同じ内容を矢印表示に切り替えます。停止経路は工程ごとの「停止条件」へまとめています。「全ノードをつなぐ」と「停止の矢印をすべて表示」で全操作・全接続を確認できます。

分岐条件はノードを選んだ詳細から確認できます。分岐ラベルが空の矢印は正常に終えた場合の次工程です。共通関数の戻り先は呼出元に応じて選ばれ、複数の戻り先へ同時に実行する意味ではありません。AIの評価観点は理解のために分解しており、内部の思考順序を保証するものではありません。

確認した範囲と限界

  • 必要な報告参照は同じ開始版で実装・修正・独立評価へ渡します。現行形式以外の参照は入力検証で拒否します。通常入口の修正・独立評価には回数・モデル時間上限がありません。有限設定の試行だけの回数・時間超過は矢印に明記しています。
  • 現行コード・skill・開発方針を読んだ静的分析です。図を作るために実モデル、GitHub公開、対象プロダクトは実行していません。
  • 通常入口と、執筆・独立評価での文書確認、撮影・公開処理、停止・中断を対象にしています。OS内部、Git/gh/モデル内部、各プロダクトのテストの中身は展開していません。
  • 既存PRの修正は人が採用した依頼から同じdevelopmentへ接続します。「引き継ぎ・運用」はローカルガイドの方針であり、現行CLIの自動機能ではありません。実装の根拠は各ノードの同梱ソースへのリンクで確認できます。文書の内容は執筆・既存の独立評価で確認し、生成PR本文の意味確認はdraft公開後へ集約します。専用校正とscopingの状態保存・gate・archiveの工程はありません。旧記録は履歴として保全します。
