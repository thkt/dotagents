## 変更と理由

実装を正しく保ったまま追加テストの検出力を評価するため、`review-probe.ts --scenario test-review` を追加します。既存の実モデル評価では、実装の不具合とテスト不足が重なっていました。

新しいシナリオでは、弱い追加テスト・妥当な追加テスト・変更なしの3条件を各1回確認します。モデルやレビュー指示を変更した際に、必要な場合だけ使います。通常CIや定期実行には接続せず、引数なしで実行する既存2ケースと予算は維持します。

モデルを起動する前に、全条件の通常テストと、別コピーへ注入した不具合の検出差を確認します。正誤の対応と判定の基準となるオラクルはホスト側に保持し、モデルの指摘と検証の申告を実際の出力に照らして裁定します。この仕組みは、読取りの物理的な隔離や自動採点を保証するものではありません。

## 検証結果と修正後の確認範囲

対象commit: `754becb392b618c1d8befa28e135077bcfeef542`

- `bun run check`：450件成功、失敗0件。候補全体と日本語文書の独立評価はacceptedです。
- 実モデルの原実測：3条件を各1回試行しました。弱いテストでは不足を指摘し、妥当なテストと変更なしでは指摘がありませんでした。内容と検証の申告は、実際の出力を独立に確認済みです。
- 保存処理の修正：独立評価で、準備途中に証拠が失われる問題が見つかり、修正しました。各段階の結果とコマンド出力を保存します。コピー時の例外やSIGTERMでも、取得済みの根拠を残してモデルの起動を抑止することを制御テストで確認しました。
- 既存の検証：入力分離・新旧選択・期限・中断・記録欠落の検証を維持しています。SIGINT/SIGTERMを実確認した後、新課題の常設接続テストはSIGTERMに集約し、共通処理には既存テストを再利用しました。

保存処理の修正では、合成課題とactor入力を変えていません。そのため、原実測を同じ課題の根拠として再利用しています。**修正後の実モデル試行は繰り返していません。**

媒体は不要です。原実測と今回の修正は[検証記録](https://github.com/thkt/dotagents/blob/754becb392b618c1d8befa28e135077bcfeef542/docs/research/test-review-scenario-20260928.md)に、操作と部分記録の読み方は[CLIガイド](https://github.com/thkt/dotagents/blob/754becb392b618c1d8befa28e135077bcfeef542/scripts/README.md#実モデルによるレビューの確認)に残しています。
