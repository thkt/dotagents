# 過去の検証報告を固定資料にし、専用生成器と常時検査を終了する

## 目的と根拠

現在の機能の検証に集中できるよう、Issue #58の過去の報告だけを再生成・照合する処理を通常の開発から外す。報告の内容と出典は保全する。

確認版はmain `e0264ad7803965074af5e998e06f04643408ed88`。[生成器](https://github.com/thkt/dotagents/blob/e0264ad7803965074af5e998e06f04643408ed88/scripts/evidence.ts#L205)は`harness-review-2026-09-14.json`を固定の入力にし、[package.json](https://github.com/thkt/dotagents/blob/e0264ad7803965074af5e998e06f04643408ed88/package.json#L13)は毎回のcheckでMarkdownとの一致を確認している。[報告](https://github.com/thkt/dotagents/blob/e0264ad7803965074af5e998e06f04643408ed88/docs/evidence/harness-review-2026-09-14.md)の実測対象は過去のcommitであり、現在の変更の検証結果ではない。

調査時点で生成器は223行、専用テストは75行。計298行が削除候補で、関連説明の更新を含む純減は実装後に確定する。新しい生成器や代替検査を追加する必要はない。

## 範囲と完了条件

- [ ] `scripts/evidence.ts`、その専用テスト、`evidence:generate`・`evidence:check`と共通checkからの呼出しを終了する。終了した機能の不在だけを検査するテストは追加しない。
- [ ] 過去のJSON・Markdown、結果・数量・未確認事項・出典・媒体参照を保全する。JSONの実測データは書き換えない。Markdown冒頭の運用案内だけを必要な範囲で更新し、固定資料であること、通常checkで一致確認しないこと、当時の生成器をGit履歴から参照できることを示す。JSONを記録の根拠として参照できる状態は保つ。
- [ ] 終了する保証を明記する。この過去報告の再生成、形式検査、JSONとMarkdownの自動一致検査は通常経路からなくなる。現在の知識データを扱う`knowledge:check`、撮影の実検証、現行runtimeとその正常系・異常系の検証は維持する。
- [ ] リポジトリ内の参照を確認し、現在の操作として終了したコマンドを案内しない。過去の記録を現行の成功証拠に読み替えず、修正前の説明はGit履歴から辿れるようにする。
- [ ] 変更前後の差分で報告内容の保全を確認し、`bun run check`と既存の独立評価・日本語確認を通す。ファイル不在やテスト件数の固定を目的とする常設テストは作らない。

## 削減評価と引き継ぎ

実装・テスト・文書の増減を既存のPRへ記す。通常checkの専用検査1つは減るが、ローカル詳細図ではcheckノード内の処理であり、ノード・矢印の純減を約束しない。同じ粒度で実際に変わる部分だけを報告し、速度改善は測定せずに断定しない。

対象は`thkt/dotagents`。セットアップは`bun install --frozen-lockfile --ignore-scripts`。提出前は`bun run check`、公開時は同じheadの`checks`・`verify`、draft本文の確認を行う。画面媒体は不要。内部記録は既存のcheckout外のrunへ置き、新しい保存台帳は作らない。

2026-09-20、依頼者は全体の冗長性調査を求め、記録を保全して専用生成器を終了する優先案の提示後に「進めて」と指示した。その範囲を実装用Issueへ整理する。テスト整理の #159 / PR #160とは、現役の機能を保つテスト整理と、過去専用機能の終了という点で範囲が異なる。着手時は最新の採用版を再確認する。今回のコード変更・実行検証・別評価者による独立評価は未実施で、本文と固定版リンクを実装へ引き継ぐ。
