## 保存・共有・変更の扱い

- `sourcePath`は元checkoutからの相対パスです。新しいcloneに原本が共有済みという意味ではありません。
- `sha256`と`gitBlob`は内容の識別です。採用・公開許可とは分けます。`originCorrespondence`はローカル参照の比較、`publicIssueCorrespondence`はGitHubから取得した本文・状態・採否の照合です。
- 現物119件のresearch資料は#259の共有対象で、#260の記録したcommitから辿れます。`sourcePublication`で許可、内容確認、実際の公開、分類時点の未マージを分けました。既存公開blob、歴史blob、公開範囲を確認できない資料も別に記録しています。許可は秘密・個人情報やローカル絶対パスを未確認で転載する意味ではありません。
- `publicExtraction.paths`が空の資料にも、原本に残す具体的な理由があります。価値なし・未読という一律の判定ではありません。この一覧は今回の移行用で、日常運用の必須台帳にはしません。
- 初回hash記録後に変更された`first-reader-ja-trial-20260919.md`は初回hashを残し、現物のhashと意味の再確認を`observedChangeAfterInventory`へ追記しました。
